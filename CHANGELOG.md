# Changelog

## 0.2.0 - 2026-09-11

- Added resumable job manifests with per-track hashes, statuses, retries, and timestamps.
- Added background operation progress with bounded concurrency, cancellation, and finalizer phases.
- Added card fingerprints, append previews, destructive truncate confirmation, and readback validation.
- Added deterministic resolution of existing Yoto user/public icons; custom image upload is no longer part of the workflow.
- Added append, operation status, operation cancellation, job manifest, and safe truncate MCP tools.

## 0.1.0

- Initial secure local OAuth PKCE MCP server for Yoto read and write workflows.
